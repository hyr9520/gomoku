# 巡天 · 太阳系互动图鉴（Solar Atlas）

一个**单文件、零依赖、可完全离线运行**的太阳系互动网页。

## 立即使用

- **最简单**：双击 `index.html`，用任意现代浏览器打开即可。
- **本地服务器**（可选）：`node serve.js` 后访问 `http://127.0.0.1:8642`。
- **部署上线**：把 `index.html` 单个文件扔到任意静态托管即可（GitHub Pages、Vercel、Netlify、云存储静态网站……），无需构建、无需后端。

## 功能

**太阳系 · 真实模拟**
- 八大行星 + 冥王星按 J2000 历元推算公转方位，打开页面即与真实天空大致相符
- 真实行星贴图（NASA 影像绘制），地球独立云层与夜面城市灯光，晨昏线光照
- 月球绕地球（27.3 天周期）；哈雷彗星沿偏心率 0.967 的椭圆逆行，彗尾始终背向太阳
- 土星环按真实结构绘制（卡西尼缝 / 恩克缝）；木星、土星的伽利略卫星与提坦随特写浮现

**深空 · 广大视野**
- 小行星带（谷神星 / 灶神星 / 智神星 / 婚神星可点开档案）+ 柯伊伯带冰封环带
- 阋神星、鸟神星、妊神星、塞德娜：缩放到最远可见 506 AU 外的塞德娜轨道（周期 11400 年）
- **四层宇宙，一直缩下去**：太阳系 → 星际邻域（太阳周围 12 光年，13 颗真实恒星可点档案：比邻星、南门二、天狼星、天苑四……）→ 银河系（四条旋臂 + 银心黑洞人马座 A* + "您在这里"）→ 本星系群（仙女座 M31、三角座 M33、大小麦哲伦云……均可点档案、点击飞行跳转）
- 河外星系背景（旋涡 / 椭圆星系）、超新星偶发爆发、银河星野、流星

**性能 · 流畅第一**
- 逐点星野/环带全部离屏烘焙，每帧位数毫秒级；启动只生成必要纹理，秒开
- 触屏设备自动降载（纹理/星点/星系数量减半，DPR 钳制）

**交互 · 全端适配**
- 桌面：拖拽平移 / 滚轮缩放 / 悬停信息卡 / 双击天体特写 / 双击空白回全景
- 手机：单指拖动、双指捏合缩放、点按选择、双击聚焦，自动降载保流畅
- 测距工具（真实 AU + 光程）、任意两天体数据对比、时间机器（16 档流速 + 日期跳转 + 年份穿越 1900–2100）、PNG 截图导出、8 题天文测验、巡天手记
- 快捷键：`空格` 播放/暂停 · `0` 太阳 · `1–8` 水星到冥王星 · `+`/`-` 缩放 · `M` 测距 · `C` 截图 · `Esc` 关闭面板

## 数据与素材来源

- 行星数据：[NASA NSSDCA Planetary Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/)（2025-03 版）
- 行星影像贴图：[Solar System Scope Textures](https://www.solarsystemscope.com/textures/)（CC BY 4.0，基于 NASA 影像绘制），已转 base64 内嵌进 `index.html`，离线可用；`assets/` 存放原始贴图，改动后运行 `node build-tex.js` 重新注入
- 轨道位置为匀速圆轨道近似（哈雷彗星为真实偏心率椭圆），适合示意方位，非天文历表
