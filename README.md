# 巡天 · 太阳系互动图鉴（Solar Atlas）

一个**单文件、零依赖、可完全离线运行**的太阳系与星际互动网页。

## 立即使用

- **最简单**：双击 `index.html`，用任意现代浏览器打开即可。
- **本地服务器**（可选）：`node serve.js` 后访问 `http://127.0.0.1:8642`。
- **部署上线**：把 `index.html` 单个文件扔到任意静态托管即可（GitHub Pages、Vercel、Netlify、云存储静态网站……），无需构建、无需后端。

## 功能

**太阳系 · 真实模拟**
- 八大行星 + 冥王星按 J2000 历元推算公转方位，打开页面即与真实天空大致相符
- 真实行星贴图（NASA 影像绘制），地球独立云层与夜面城市灯光，弧形晨昏线光照
- 月球绕地球（27.3 天周期）；哈雷彗星沿偏心率 0.967 的椭圆逆行，彗尾随日距分级变化
- 11 类地表动态事件：尘暴、鸟群、流星雨、极光、雷暴、风暴带、环雨、钻石雨、卫星凌影、火山喷发、甲烷雨

**地球 · 详细地图与 15 个着陆点**
- NASA Blue Marble 2048 详细地图模式：拖动缩放、经纬网格、昼夜线随游戏时间移动
- 15 个着陆点（七大洲 + 珠峰/撒哈拉/大堡礁/冰岛/乌尤尼/乞力马扎罗/马尔代夫/富士山等 POI），地图点击直接降落
- 地表三档机位、俯仰视角、扫描采样、拍照成就、观日出

**星际 · 多恒星系统**
- 星际邻域 19 颗真实恒星（含 TRAPPIST-1、织女星、鲁曼 16 等，各带档案）
- 深空扫描（X）定位信号源、跃迁引擎（N）曲速航行
- 三个可进入的恒星系统：比邻星、TRAPPIST-1（全七行星）、格利泽 581——13 颗系外行星按真实周期运行，两颗宜居世界可着陆
- 发现玩法：微生物垫遗迹、生物荧光之海——「我们不再孤独」

**叙事与收集**
- 开场与终章动态过场（AGNES 场景画）、巡天任务链六段战役、K-7 先驱者信标六段+回信
- 19 项成就、36 题天文测验、34 条巡天手记、巡天影集 11 拍摄目标
- 天象面板：月相、行星距地排行、行星动态、未来事件直达（哈雷 2061/塞德娜 2076/2100）

**技术**
- 单文件 5.97MB：全部贴图/场景画/音频 base64 内嵌，完全离线
- 四层宇宙缩放（太阳系→星际→银河→本星系群）、帧率限流、移动端适配
