# 五子棋 · 联机对战

手机浏览器打开,创建房间,把链接发给微信好友——好友点开就开打。**零依赖**,只要目标机器有 Node.js(≥16),无需 `npm install`。

```
node server.js
```

---

## 📱 如何让你和微信好友都能打开(部署到公网)

好友的手机要能点开链接,游戏必须跑在**公网服务器**上(自己电脑上跑的服务,外网好友访问不到)。三选一,按省事程度排序:

### 方式一:Render 免费部署(推荐,约 10 分钟,不要钱)

1. 注册 [github.com](https://github.com) 账号,把本项目文件夹上传为一个仓库(网页上点 Upload files 拖进去即可,也可以用 git 命令)。
2. 注册 [render.com](https://render.com)(可用 GitHub 账号直接登录)。
3. 控制台 **New → Web Service → 连接你刚建的仓库** → 保持默认(会自动读取 `render.yaml`/`Procfile`,启动命令 `node server.js`)→ **Create**。
4. 等一两分钟,得到一个 `https://你的应用.onrender.com` 地址——这就是你要的永久链接。
5. **手机浏览器打开它 → 创建房间 → 复制链接发给微信好友**,好友在微信里点开即战。

> 免费版 15 分钟无人访问会休眠,下次打开多等 30 秒左右即自动唤醒。想一直秒开可升级 $7/月,或看方式三。

### 方式二:自己的电脑 + 内网穿透(最快见效,电脑需开机)

```bash
node server.js          # 窗口 1: 启动游戏 (端口 3000)
npx localtunnel --port 3000    # 窗口 2: 获得一个公网 https 地址
```

把得到的 `https://xxxx.loca.lt` 发给好友即可。国内更稳的同类工具:`natapp`(需注册免费隧道)、`cpolar`。缺点:电脑关机链接就失效,只适合临时开黑。

### 方式三:云服务器(长期稳定)

任意 VPS(阿里云/腾讯云轻量 ≈ 每月几十元):

```bash
scp -r gomoku-online user@服务器IP:~/          # 上传
ssh user@服务器IP
cd gomoku-online && PORT=80 node server.js       # 建议用 pm2 守护: npm i -g pm2 && pm2 start server.js
```

安全组放行端口后,`http://服务器IP` 就是游戏地址。也可用 Docker: `docker build -t gomoku . && docker run -p 80:3000 gomoku`。

## 功能

- **微信分享即玩**:创建房间生成邀请链接(`https://你的域名/房间码`)与二维码,好友点链接/扫码直接进房;也可在首页输 4 位邀请码加入。
- **自定义规则**(房主建房时配置):
  - 棋盘:13 / 15 / 19 路
  - 获胜规则:**自由规则**(连五或长连≥5 均胜)/ **精确五连**(黑棋长连不算胜,白棋长连算胜)/ **连珠规则**(黑棋禁手:三三、四四、长连,禁手点有红叉标记)
  - 先手:房主执黑 / 对方执黑 / 随机
  - 每步限时:不限 / 30 秒 / 60 秒 / 3 分钟(超时判负)
  - 悔棋:允许(需对方同意)/ 不允许
- **对局体验**:落子/胜利音效、最后一手标记、胜利连线高亮、悔棋 / 求和 / 认输、再来一局(自动交换先后手)、每步倒计时。手机竖屏自适应,小屏也可玩。
- **断线无忧**:刷新或断网自动重连回原座位(对战中断线 60 秒内回来不判负);满员后来者自动观战。
- **服务端权威**:落子、禁手、胜负、超时全部服务端判定。

## 本机体验

```bash
node server.js
```

- 电脑浏览器打开 `http://localhost:3000`
- 手机连同一 WiFi,打开启动时打印的 `http://局域网IP:3000`
- 同一浏览器开两个标签页也能自己和自己下(各标签页独立身份)

## 目录结构

```
index.html          界面结构
style.css           深绿呢桌面 + 木纹棋盘 + 朱砂/金 配色
app.js              前端逻辑: 连接/重连、房间流程、分享、倒计时
board.js            Canvas 棋盘渲染 (木纹/棋子/动画/禁手标记/胜利高亮)
sound.js            WebAudio 合成音效 (无素材文件)
qrcode.js           二维码生成 (qrcode-generator, MIT)
server.js           入口: 静态页面 + WebSocket 服务 + /info 局域网地址
game.js             房间与对战逻辑 (服务端权威)
ws.js               零依赖 WebSocket 实现 (RFC 6455)
rules.js            规则引擎 (前后端共用): 胜负 / 禁手 (含递归假活三判定)
test/               34 个自动化测试 (规则 / WebSocket / 协议级 E2E)
render.yaml         Render 部署配置
Procfile            Railway/Heroku 类平台启动声明
Dockerfile          容器镜像
```

## 已知边界

- 房间数据保存在内存,进程重启后房间清空(对战类应用常规做法)。
- 每步超时判负未纳入自动化测试(需等待真实时长),逻辑为服务端简单 `setTimeout`,已人工核验。
- 微信里点开普通链接即可玩;若要自定义微信分享卡片的标题/缩略图,需公众号 JS-SDK,本项目未包含。
